# PhiAutoRender

PhiAutoRender 是一个基于 Python 的自动化渲染 Phigros 谱面的工具。

## 功能
- 自动下载 Phigros Apk
- 自动解包
- 支持识别新歌曲、追加AT、改谱、删除谱面四大更新
- 自动构建 MD5 表，极速识别更新内容
- 自动渲染
- 自动生成视频封面
- 自动上传到 Bilibili
